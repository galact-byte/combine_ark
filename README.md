# 奇象巡展 · 像素拼豆助手

这是一个仅在本地运行的 Windows 小工具：导入 PNG 或 JPG/JPEG 后，将图片转换为明日方舟「奇象巡展」拼豆编辑器可用的 **24×24、固定 40 色**图案。你可以导出图纸手工填写，也可以在确认与校准后让工具向 **PC 客户端前台窗口**逐格点击填色。

仓库地址：<https://github.com/galact-byte/combine_ark>

## 下载与安装

### 方式一：直接下载 exe（推荐普通用户）

前往 [Releases](https://github.com/galact-byte/combine_ark/releases) 下载最新的 `ArkPixelHelper.exe`，双击即可运行，无需安装 Python。自动填色需要管理员权限，首次运行会弹 UAC。

### 方式二：从源码运行（开发者）

需要 Python 3.11 或更新版本。

```bash
python -m pip install -r requirements.txt
python main.py
```

运行后会直接打开图形窗口；本程序没有命令行参数。

## 打包发布

推送形如 `v1.0.0` 的 tag 后，GitHub Actions 会在 Windows runner 上用 PyInstaller 打包单文件 exe 并自动发布到 Release（见 `.github/workflows/build.yml`）。本地也可手动打包：

```bash
python -m pip install pyinstaller
pyinstaller --onefile --noconsole --name ArkPixelHelper main.py
```

> 如果只使用导图、手工修正和图纸导出，Pillow 即可工作。自动填色的窗口截图、网格识别、SendInput 注入与提权均基于 Python 自带的 `ctypes` + Pillow，无需额外依赖。

## 使用顺序

1. 点击 **导入 PNG / JPG 图片**。选择文件后会先打开裁切确认页，取消不会覆盖当前图案或记忆目录；首次默认打开当前 Windows 用户的“图片”目录，确认后才记住新目录。
2. 在裁切确认页用正方形框住人物的脸部、双眼和发型：拖动框内移动、拖动四角调整边长，滚轮围绕指针缩放。确认后的原图坐标区域是唯一转换来源；需要调整时点击 **重新裁切图片**，会保留上次框选位置。
3. **更多颜色细节（完整 40 色候选）** 是默认策略，适合保留眼睛、高光和局部发色；也可改为 **清晰轮廓（最多 16 主色）**，压缩噪点和零散颜色。照片或插画默认使用平滑取样，已有像素画可切换最近邻；可选抖动仅在更多颜色细节策略下生效，会增加颗粒感。
4. 已确认框选后，原图先缩至 24×24，再轻度增强明暗和饱和度分离并量化到固定游戏 40 色。中间画布默认只显示像素颜色；需要时勾选预览区右上的 **显示色号**。点击任一格子选中它（不会直接改色），再在右侧色号表点选颜色即可修正。
5. 需要手工填写时，分别导出 **带网格图纸 PNG** 与 **逐格色号 CSV**。CSV 中的数字是游戏内显示的 1–40 色号。

## 自动填色：先校准，后确认

自动填色是主流程，但必须由你明确开始：

1. 以**管理员身份**启动本工具（`python main.py` 非管理员时会自动弹 UAC 请求提权并重启）；提权是游戏接受注入的必要条件。在 PC 客户端打开拼豆编辑器并保持布局不变。
2. 确保游戏处于**拼豆编辑器页**（能看到画布和右侧色板）。点击 **捕获游戏窗口并识别画布**，再点 **3 秒后捕获并识别画布**；倒计时结束时让游戏编辑器保持前台。工具会绑定该窗口及进程、截图，自动识别画布 24×24 网格线，并用已知 40 色在右侧面板“认色板”——后者对 **UI 缩放/分辨率免疫**（你游戏里的 UI 缩放不是 100 也能对）。
3. 在预览图上核对：**绿框**为识别到的画布，**蓝框**为识别到的色板。两者都对就点 **确认使用**；若哪个是**橙框**（识别失败已回退估计），把该元素完整露出后点 **重新识别**。校准只写入当前 Windows 用户应用数据目录，不会写入游戏目录。
4. 点击 **开始自动填色（需确认）**，确认说明后有 3 秒切回游戏窗口。
5. 工具会确认当前前台仍是校准时绑定的游戏窗口与进程；不匹配时**不会发送任何点击**。匹配后，按实际客户区/DPI 换算保存的相对校准位置，不依赖任何固定分辨率。
6. 它按色号分组：每选一种颜色连续填写对应格子；色号 25–40 会拆成多次单刻度滚轮、每次重锚切到底部色板；默认跳过白色（色号 4）格子。鼠标点击采用 SendInput 双路注入（先发相对位移喂 Raw Input，再发绝对坐标校光标）。

### 安全停止

- 自动化只在确认后发送前台鼠标输入；不使用后台注入、窗口消息或绕过输入机制。
- 填色时可以点击 **停止后续点击**；正在进行的单次点击结束后不会继续点击。每次点击前都会重新核验前台窗口句柄和进程是否仍匹配校准时的游戏；失焦、关闭或切换到其他窗口都会在下一步前停止，避免向其他应用发送后续点击。
- 按 **F8** 可随时全局急停（取代旧的“鼠标移到屏幕左上角”，因为相对位移注入会误触发左上角）。
- 若校准无效、游戏不在前台、依赖未安装或过程被中断，工具会停止；已填写部分保留在游戏画布，可按已导出的图纸继续。

## 隐私与限制

- 图片处理、量化、图纸导出和校准均离线在本机完成；不会上传图片或访问网络。
- 不读取、修改游戏文件、账号信息或网络数据。
- 仅支持 Windows 上的 PC 客户端；不支持 Android 模拟器、ADB、移动端、自动发布或保存游戏作品。
- 24×24 与 40 色存在固有限制，复杂照片无法无损还原。优先紧凑框选头部和双眼；若预览有零散噪点，再切换到“清晰轮廓”并进行手工微调。
