# 奇象巡展 · 像素拼豆助手

这是一个仅在本地运行的 Windows 小工具：导入 PNG 或 JPG/JPEG 后，将图片转换为明日方舟「奇象巡展」拼豆编辑器可用的 **24×24、固定 40 色**图案。你可以导出图纸手工填写，也可以在确认与校准后让工具向 **PC 客户端前台窗口**逐格点击填色。

## 安装与启动

需要 Python 3.11 或更新版本。

```bash
python -m pip install -r requirements.txt
python main.py
```

运行后会直接打开图形窗口；本程序没有命令行参数。

> 如果只使用导图、手工修正和图纸导出，Pillow 即可工作；`pyautogui` 只在点击“开始自动填色”时才会加载。

## 使用顺序

1. 点击 **导入 PNG / JPG 图片**。首次默认打开当前 Windows 用户的“图片”目录；成功导入后会记住上次目录，仍可自由选择任意本地目录。
2. 选择构图方式：
   - **裁剪（可调构图）**：用横向/纵向滑块把主体移入正方形区域；
   - **完整包含（白底留白）**：保留整图，用白色补足边缘；
   - **拉伸**：强制拉为正方形。
3. 照片或插画使用默认“平滑取样 + 减少杂色”；已有像素画可切换“最近邻”。转换结果最多使用游戏内固定 40 色，减少杂色启用时会优先保留最多 16 个主要色块。关闭减少杂色后可选择误差扩散抖动，但它会增加颗粒感，默认不建议用于保持主体轮廓。
4. 中间画布默认只显示像素颜色，便于整体看像不像；需要时勾选预览区右上的 **显示色号**。点击任一格子选中它（不会直接改色），再在右侧色号表点选颜色即可修正。
5. 需要手工填写时，分别导出 **带网格图纸 PNG** 与 **逐格色号 CSV**。CSV 中的数字是游戏内显示的 1–40 色号。

## 自动填色：先校准，后确认

自动填色是主流程，但必须由你明确开始：

1. 在 PC 客户端打开拼豆编辑器，并保持其布局不变。
2. 点击 **手动校准游戏画布与色板**，再点 **3 秒后捕获当前游戏窗口**；倒计时结束时让游戏编辑器保持前台。工具会绑定该窗口及进程、读取实际客户区，并按当前尺寸预填画布、顶部色板、底部色板和滚轮建议值。
3. 对照当前游戏界面核对并微调建议值：画布必须包住完整 24×24 网格；顶部色板填初始可见 6 行；滚到底部后填写底部色板可见区域及实际所需滚轮档数。保存校准只写入当前 Windows 用户应用数据目录，不会写入游戏目录。
4. 点击 **开始自动填色（需确认）**，确认说明后有 3 秒切回游戏窗口。
5. 工具会确认当前前台仍是校准时绑定的游戏窗口与进程；不匹配时**不会发送任何点击**。匹配后，按实际客户区/DPI 换算保存的相对校准位置，不依赖任何固定分辨率。
6. 它按色号分组：每选一种颜色连续填写对应格子；色号 25–40 会按你校准的滚轮档数切到底部色板；默认跳过白色（色号 4）格子。

### 安全停止

- 自动化只在确认后发送前台鼠标输入；不使用后台注入、窗口消息或绕过输入机制。
- 填色时可以点击 **停止后续点击**；正在进行的单次点击结束后不会继续点击。每次点击前都会重新核验前台窗口句柄和进程是否仍匹配校准时的游戏；失焦、关闭或切换到其他窗口都会在下一步前停止，避免向其他应用发送后续点击。
- `pyautogui` 的安全机制已启用：把鼠标移到屏幕左上角会停止自动化。
- 若校准无效、游戏不在前台、依赖未安装或过程被中断，工具会停止；已填写部分保留在游戏画布，可按已导出的图纸继续。

## 隐私与限制

- 图片处理、量化、图纸导出和校准均离线在本机完成；不会上传图片或访问网络。
- 不读取、修改游戏文件、账号信息或网络数据。
- 仅支持 Windows 上的 PC 客户端；不支持 Android 模拟器、ADB、移动端、自动发布或保存游戏作品。
- 24×24 与 40 色存在固有限制。复杂照片无法保证细节还原，建议裁剪主体、减少杂色后再进行手工微调。
