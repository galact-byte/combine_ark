# 技术设计：奇象巡展像素拼豆助手

## 技术选择

采用 Python 3.11+、标准库 `tkinter` 和 Pillow；测试使用 `pytest`。这是 Windows 本地单文件启动型工具，避免浏览器、服务端、ADB 和在线依赖。Pillow 负责图片读取、裁剪、缩放、导出；tkinter 负责界面、文件选择与预览。

自动点击仅使用 Windows API 的前台鼠标输入，隔离在 `ark_pixel_helper.autofill` 中。核心图像处理、图纸导出和自动点击互不依赖：窗口定位/校准失败时，图纸与手工修正仍可完整使用。

## 核心数据契约

- `PALETTE: tuple[RGB, ...]`：唯一允许的 40 色，索引 `0..39` 对应向用户展示的色号 `1..40`。
- `Pattern.cells: list[list[int]]`：固定 24 行、每行 24 个调色板索引。构造时验证维度及色号范围。
- `ImageOptions`：`fit_mode`（`crop`/`contain`/`stretch`）、`resample`（`smooth`/`nearest`）、`matcher`（`oklab`/`rgb`）、`reduce_colors`（布尔）、`dither`（布尔）。`reduce_colors` 启用时关闭抖动，优先清晰轮廓。
- `Calibration`：客户区左上角、宽高、网格矩形、顶部/底部色板色块中心坐标及滚动锚点；坐标以当前实际客户区与当前 DPI 尺寸计算，自动定位结果可被用户校准覆盖。保存到用户本地配置，不写入游戏目录。
- `AppSettings`：上次成功导图目录和窗口校准配置，写入用户应用数据目录；首次目录由 `Path.home() / "Pictures"` 等系统候选目录动态解析，绝不存储项目预设的用户盘符路径。

## 数据流

1. UI 导入本地图片，透明像素合成到白底。
2. 用户选择构图和处理选项；管线输出 `Pattern`。
3. UI 放大显示网格，允许修改单格；`Pattern` 是唯一编辑状态。
4. 导出器从当前 `Pattern` 生成图纸 PNG 和 UTF-8 CSV；不从预览截图反推数据。
5. 自动绘制读取当前 `Pattern` 和已确认 `Calibration`，跳过白色索引 3，把格子按色号分组后，依次点击游戏调色板和目标画布格；它应把导入图片转换后的结果实际画进奇象巡展编辑器。图纸导出只负责预览、修正和自动化故障兜底。

## 图像质量策略

先实现稳健基线：居中裁切/留白/拉伸、Pillow 缩放、OKLab 最近色量化。默认使用平滑缩放+OKLab+减少杂色，避免 24×24 的照片出现大量零散色点；对已是像素画的导入图，用户可切换最近邻。低频颜色合并至占比最高的 16 色候选后再量化，只在“减少杂色”启用时执行。用户始终可手调最终格子。

## 界面视觉与交互

采用“奇象巡展夏日像素工坊”功能型方向：`#e3f2ef` 薄荷底、`#ffffff` 面板、`#153230` 主文本，`#0fb6a6` 作为主要操作高亮，`#f5893a` 用于自动绘制风险/警告。顶部为青碧到湖蓝的活动横幅，允许少量暖橙/奶白星芒装饰；主体三栏为左侧导入与转换控制、中部放大画布、右侧游戏色板与导出/自动化区。仅头图和实际 40 色色块承担强色彩，其他面板保持清爽。

使用细线框、分段标题和等宽数字，营造轻量游戏编辑器感；不使用玻璃、浮动卡片堆叠、圆角药丸或影响操作的动效。按钮按危险性分层：导入/导出是浅色描边次级按钮，应用转换是青碧实色主按钮，自动填色使用暖橙实色并在确认后才启用；开始、取消、进度均具文字说明，不只使用颜色。鼠标优先的 24×24 画布允许紧凑的 22px 网格，选中格有高对比描边；右侧色板与关键按钮保持清晰可点。状态变化仅使用低干扰颜色/透明度反馈。

## 自动填色安全与兼容性

- 仅在用户点击“开始自动填色”并通过确认弹窗后运行。
- 每次点击前检查取消事件；鼠标移到屏幕左上角也可触发 pyautogui 的安全停止。
- 启动前检查目标窗口与校准数据；未通过时只允许进入手动校准界面，绝不猜测坐标直接点击。
- 比例坐标只作为首次定位的启发式值，网格和色板锚点始终按实时游戏客户区和 DPI 换算；自动识别失败或 UI 布局变化时，必须使用用户保存的当前窗口校准，不能把任何分辨率当作运行前提。
- 向游戏发送前台鼠标点击，不尝试后台注入、窗口消息或绕过输入机制。

## 错误、隐私与回滚

图片读取、导出路径、窗口定位、自动化调用均捕获预期异常并在 UI 展示中文原因及恢复建议。处理过程和导出仅访问用户明确选择的本地文件；不收集账户、网络或游戏文件数据。自动填色失败可立即停止，已填部分保留在游戏画布，用户可从图纸继续；不提供自动撤销或自动发布。
